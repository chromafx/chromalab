# Lucide icon subset

Stroke SVG icons from [Lucide](https://lucide.dev) (ISC; Feather-derived icons MIT).

Path data used at runtime is generated into `Controls/LucideIconData.cs`.
License text: repo root `THIRD_PARTY_NOTICES.md`.

To refresh path data after adding/updating SVGs here:

```bash
# from chromalab/
python3 scripts/gen-lucide-icon-data.py
```
